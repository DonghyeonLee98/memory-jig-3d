# 메모리 소자 측정 지그 3D

crossbar 메모리 소자(할라이드 페로브스카이트 ReRAM)를 재는 장비의 3D 보기와 연습 페이지.

- 1세대 (2026-10-26 결정): 솔라셀 지그 몸체에 SM 보드(핀 12, DB15)를 끼운다. 셀 8개(1 × 8 crossbar). 연습: `assembly.html`(조립하는 법), `measure.html`(연결하는 법). 숫자는 설계 파일이 오면 다시 맞춘다. SM 지그 3D는 모델이 나오면 추가.
- 2세대 (보관): 아래 XB16 지그 · 8 × 8 기판.

- XB16 지그: 스프링 핀 16개가 기판 패드에 닿는 받침·틀·뚜껑·DB25 블록 (분해 보기, 층 표, 부품 설명)
- crossbar 기판: 아래 선 B1–B8, 페로브스카이트, 위 Ag 선 T1–T8 (막 두께 40배로 그림)
- 증착 세트: 마스크 X1 + 기판 등록 틀 + 기판
- MEM-MUX16 릴레이 보드: 부품 몸체만 상자로

2026-10-24 설계 검토를 반영한 판이다. 형상은 설계용 개념 모델(STEP과 같은 치수)이고 제작도가 아니다.
홀더 포켓 26.54 mm는 가정값이다.

three.js r128, 모델은 `mem_models.js` 안에 GLB(base64)로 들어 있다.
